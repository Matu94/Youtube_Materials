# YouTube Materials 🎥

Welcome to the official repository for my YouTube channel **[`@MatuData`](https://www.youtube.com/@MatuData)**! 

This repository serves as a central hub for all the materials featured in my YouTube videos and tutorials. Here you will find:
- 📜 **Scripts**: Code scripts and snippets used during the tutorials.
- 📊 **Raw Data Files**: Datasets and files required to follow along with the projects.
- 🛠️ **Other Resources**: Any additional materials or assets mentioned in the videos.

## 📂 Courses & Videos

Each folder in the root corresponds to a specific video or course:

- **[Snowflake Tables & Views](./Snowfalke%20Tables%20&%20Views/README.md)** — Complete guide to Snowflake tables, micro-partitions, pruning, zero-copy cloning, and Time Travel using the SnowBite dataset.
